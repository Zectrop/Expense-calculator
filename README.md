## ✨ About PaisaLog

PaisaLog is a personal money journal that helps you manage your daily income and expenses without complicated dashboards or unnecessary features.

It provides a clean interface where you can record transactions, monitor your available balance and understand your spending habits.

No account creation. No backend. Your transaction data stays in your browser using Local Storage.

## 🚀 Features

| Feature | Description |
|---|---|
| 💰 Income Tracking | Record your income transactions |
| 💸 Expense Tracking | Keep track of daily spending |
| 📊 Balance Calculation | Automatically calculates remaining balance |
| 📝 Transaction Journal | View all your financial entries |
| 🗑️ Delete Transactions | Remove individual records |
| 💾 Local Storage | Saves data in your browser |
| 📅 Date Selection | Add transactions with specific dates |
| 📱 Responsive UI | Works on desktop and mobile |
| 🎨 Elegant Interface | Minimal, clean and modern design |

## 🎨 Design Philosophy

PaisaLog follows a simple design philosophy:

- Forest green and warm beige color palette.
- Elegant typography using DM Sans and Playfair Display.
- Minimal cards with subtle borders.
- Clean transaction history.
- Responsive layout for smaller screens.

The goal is to make financial tracking feel simple rather than complicated.

## ⚙️ Getting Started

You can run PaisaLog locally in just a few steps.

**1. Clone the repository**

```bash
git clone https://github.com/Zectrop/PaisaLog.git
```

**2. Open the project folder**

```bash
cd PaisaLog
```

**3. Run the application**

Open `index.html` in your preferred browser.

That's it! No installation, dependencies or backend configuration required.

## 🔒 Privacy & Data Storage

PaisaLog uses the browser's Local Storage API.

- Transactions are stored locally in your browser.
- No external database is required.
- No user registration or login is needed.
- Clearing browser storage may permanently remove saved transactions.

**Note:** Data is browser-specific and does not automatically synchronize across devices.
